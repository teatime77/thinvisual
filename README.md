# thinvisual
HTML-over-the-wire applications with a GUI designer

## 開発環境

- Node.js 24以上（npm付属）
- TypeScript / Express / htmx

PowerShellでリポジトリのディレクトリを開き、実行します。

```powershell
npm.cmd ci
npm.cmd run dev
```

ブラウザーで http://127.0.0.1:3000 を開くと、備品管理アプリが表示されます。
追加・在庫数の増減・不足品の絞り込みは、サーバーが返すHTMLで一覧を更新します。
htmxはローカルのnpmパッケージから配信します。

開発中は `tsx watch` がTypeScriptの保存を検知してサーバーを再起動します。
ブラウザーは手動で再読み込みしてください。Viteによる自動反映は後続の実装で追加します。
停止するには `Ctrl+C` を押します。

ポートを変える場合は、起動前に `$env:PORT = '3001'` のように指定します。
サーバーはローカルPCの `127.0.0.1` で待ち受けます。

## チェックとビルド

```powershell
npm.cmd run verify
npm.cmd start
```

`verify` は型チェック・JavaScriptへのビルド・HTTP経由の自動テストを実行します。
テストでは追加・増減・不足判定・不正入力・HTMLエスケープ・通常のフォーム送信を確認します。
`start` はビルド済みの `dist/server.js` をNode.jsで実行します。
ブラウザーでの操作確認は別途行ってください。

## 現在の範囲

備品管理の通常画面まで実装しています。

- 備品名・在庫数・最低在庫数を入力して追加できます。
- `−1` / `＋1` で在庫を変更できます。在庫は0未満にできません。
- 在庫数が最低在庫数より少ない場合に「補充が必要」と表示します。
- 「在庫が少ない備品だけ表示」で一覧を絞り込めます。
- 不正な入力は赤色で表示し、データを変更しません。

データはメモリ上で保持します。ブラウザーの再読み込みでは保持されますが、
開発中のコード保存によるサーバー再起動や、プロセス停止で初期データへ戻ります。
複数のブラウザーは同じデータを共有します。他のブラウザーでの変更は再読み込みすると反映されます。
DBへの永続化、デザイナーモード、ts-morphによる型情報表示は後続の実装です。

## ソースの構成

- `src/app/logic.ts`：備品データ、追加・増減、`needsRestock`による補充判定。
- `src/app/view.ts`：Flexbox / Gridを使う画面とHTML断片の生成。
- `src/http.ts`：フォーム受付、HTML応答、通常フォームのリダイレクト。
- `src/server.ts`：ローカル開発サーバーの起動。

現時点ではすべて手書きのソースです。デザイナーによるTypeScript生成は未実装です。
